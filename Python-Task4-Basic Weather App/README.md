# 🌦️ Weather Now — Python Weather App

A desktop weather application built using Python and Tkinter that displays real-time weather information and forecasts using the OpenWeatherMap API.

## 📌 Project Overview

Weather Now allows users to search for a city and view its current weather conditions, temperature, humidity, wind speed, and upcoming forecasts through a modern graphical interface.

## ✨ Features

- Search weather by city name or ZIP code
- Real-time weather information
- Temperature in Celsius and Fahrenheit
- Humidity and wind speed display
- Weather condition icons
- Next 6 forecast intervals
- 5-day weather outlook
- Automatic location detection using IP address
- GUI-based error handling
- Dark-themed Tkinter interface

## 🛠️ Technologies Used

- Python
- Tkinter
- Requests
- Pillow
- OpenWeatherMap API
- ipinfo.io API

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Basic-Weather-App.git
```

### 2. Navigate to the project

```bash
cd Basic-Weather-App
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Configure your API key

Get a free API key from [OpenWeatherMap](https://openweathermap.org/appid).

In Windows PowerShell:

```powershell
$env:OPENWEATHER_API_KEY="YOUR_API_KEY"
```

### 5. Run the application

```bash
python weather_app.py
```
